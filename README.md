# 小镇居民（townfolk）

Minecraft NeoForge 1.21.1 模组。居民不是站着等玩家的 NPC，而是有自己的工作、作息、家庭和钱，会互相买卖；玩家是镇长，负责规划和管理小镇。

需要前置模组 **GeckoLib 4.9.3**（开发环境里 Gradle 会自动下载）。

## 现在有什么

- **镇公所**：放下即建镇，开局 6 位居民。界面里有总览、居民、时间表、地图。
- **上帝视角规划**：在地图里拖出矩形划分区（农业、轻工业、重工业、居民区、商业区），右键分区选具体用途。
- **职业**：农夫（自动规划水坑、开垦、播种、收割）、伐木工（错落种树、砍树、补种）、店员。只要给分区设工作人数，分区会自己招住得最近的无业居民。
- **居民**：有性别和年龄，2 个游戏日长 1 岁，18 岁成年，会结婚、搬家、生孩子、老死。
- **住房**：独栋（一个分区一户）和楼房（按门自动分户）。
- **时间表**：全镇共用，工作、休息、睡觉、自由、吃饭，可以在游戏里逐个钟点改。
- **经济**：金币、每人的钱包、小镇金库和安家费；货架、柜台、集市摊位能摆出货物的立体模型；居民按需要去货架拿货、到收银台排队结账；店员自己按销量调价。

## 在另一台电脑上继续开发

1. 安装：
   - [Git](https://git-scm.com/)
   - **JDK 21**（例如 [Temurin 21](https://adoptium.net/)）
   - Claude Code
2. 把仓库拉下来：
   ```
   git clone <这个仓库的地址>
   ```
3. 用 Claude Code 打开拉下来的文件夹，对它说“继续做这个项目”。
   仓库根目录的 `CLAUDE.md` 会自动告诉 Claude 这个项目是什么、之前定了哪些设计、做到哪一步、下一步是什么；完整的记忆原件在 `docs/claude-memory/`。
4. 启动游戏：双击 `run-client.bat`，或者运行 `gradlew runClient`。第一次会下载 Minecraft 和依赖，要等几分钟。

不会跟着仓库走的东西：游戏存档（`run/saves/`）和截图。想带走测试存档的话，手动把 `run/saves/` 里的文件夹拷到新电脑的同一位置。

## 常用命令

| 命令 | 作用 |
| --- | --- |
| `gradlew runClient` | 启动带模组的游戏 |
| `gradlew runGameTestServer` | 跑全部自动测试 |
| `gradlew runSmoke` | 自动开游戏走一遍流程并截图到 `run-smoke/screenshots/` |
| `gradlew build` | 打包，产物在 `build/libs/` |

## 目录

- `src/main/java/com/townfolk/` 源码
- `src/main/resources/` 贴图、模型、动画、语言文件
- `tools/` 生成贴图、模型、动画的脚本
- `docs/claude-memory/` 开发过程中的设计决定和环境说明
